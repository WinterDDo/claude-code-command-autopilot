#=SECTION safety

#=SECTION unlock
BETTER-MOVE CHECK (the user's standing request — why they installed this). Treat your installed skills AND your slash-commands as ONE toolset. Each turn, for the user's task:
- If one tool (skill or command) is clearly the best fit and it's cheap/safe → just USE it (say so in a line; for a trivial ask, silently). Don't ask when the move is obvious.
- If 3-4 tools or combos genuinely fit → present them as a clickable AskUserQuestion menu (each: tool + one-line payoff) + "just proceed" — the real popup, not a prose list. Don't decide alone when several compete.
High-leverage moves to weigh next to the skills: a Workflow / parallel agents, /goal, /loop, /fork, background, deep research, plan mode (substantial build → plan mode before editing). Lead with the work and the tool, not with narration of your process.
Stay silent for a trivial one-step ask, a tool already used/declined this turn, or a small mid-task follow-up; a tool offered or declined stays closed — don't re-pitch it. Recalling the user's own past pattern (see EVIDENCE/LEARNED) is often the best move. "quiet"/"mute" silences all.
